## 🧩 Project Overview
Traditional shopping is time-consuming and limited by store availability.  
The **Online Shopping Cart System** provides customers with a convenient digital platform to browse products, add them to a cart, and complete their purchases seamlessly — all in one place.

This web-based solution also helps small-scale businesses manage their product listings and track customer orders more efficiently.

---

## 🎯 Key Features
### 👤 User Authentication
- Secure login system for **customers** and **admin** roles.  
- Customers can browse products, while admins manage listings.

### 🛍️ Product Catalog Management
- Add, update, and delete products (admin only).  
- Search and filter products by **category**, **price**, or **name**.  
- View detailed product descriptions and stock availability.

### 🛒 Add-to-Cart Functionality
- Customers can add items to their cart and update quantities.  
- Cart contents are visible before checkout with total price calculation.

### 💳 Checkout & Payment
- Place orders with detailed confirmation of items and quantity.  
- (Optional future feature) Integration with secure online payment gateways.

### 🧾 XML-based Order History
- Orders are stored in structured **XML format**.  
- Both admin and customers can view and track past orders.

### 📦 Customer Profiles
- Each user has a profile containing contact information and order records.

### 📈 Reports & Analytics
- Generate sales reports by **product**, **category**, and **time period**.  
- Export data in **XML/Excel** format for analysis.

### 📢 Notifications & Alerts
- Email/SMS notifications for placed orders.  
- Admin alerts for **low-stock** or **out-of-stock** products.

### 🔐 Security & Scalability
- Data encryption for secure handling of personal information.  
- Scalable architecture to support increasing users and products.

## 🚀 How to Deploy (GitHub Pages)
1. Download the `deploy_bundle.zip` provided with the project.  
2. Extract it and open the `static_site/` folder.  
3. Create a **new GitHub repository** (public).  
4. Upload all files inside `static_site/` (keep `index.html` at the root).  
5. Go to **Settings → Pages** → Enable GitHub Pages from the `main` branch.  
6. Visit your live site at:  
   `https://<your-username>.github.io/<repo-name>/`
